网络漫游白话小词典 · 核心概念一览

NO TECH JARGON · 100% 白话
🥪

节点 (Node / Server)

白话：相当于你在海外租用的一台高速电脑跳板。你的访问请求先发给它，由它代你前往海外网站并把结果传回给你。

📦

订阅链接 (Subscription)

白话：装满成百上千个节点服务器地址与密码的「配置清单链接」。客户端读取一次就能自动拉取全部节点，不用一个个手动敲。

🧭

规则分流 (Rule Routing)

白话：客户端自带的「交通警察」。国内网站（淘宝/微信）直连本地宽带，海外网站（YouTube/Google）才引导走节点，互不干扰。

💡

Fake-IP 模式

白话：快速发出的「取餐号码牌」。客户端收到解析请求后立即给应用返回一个 198.18 虚拟 IP 省去本地 DNS 等待，实现秒开。

🛡️

TUN 虚拟网卡

白话：在系统里插上一根虚拟网线，强行接管电脑的所有流量。连没有代理设置开关的游戏、命令行或特殊软件也能被加速。

🚇

IPLC / IEPL 专线

白话：公网中继像走繁忙的跨洋国道，晚高峰易拥堵丢包；专线则是运营商拉的海底专用直达光纤，不经公网，晚高峰极其平稳。

⚠️ 新手避雷清单 · 5条铁律
1. 本地时间误差 < 60 秒
时间不对会导致 TLS 握手校验硬失败，节点全报 Timeout。
2. 切忌长期开「全局代理」
误开 Global 会让微信、银行等国内流量绕道海外导致异常。
3. 关软件前先退出代理
强退软件会残留注册表代理，导致下次开机所有网页无法打开。
4. iOS 认准外区 Apple ID
国区 App Store 搜索不到小火箭，需准备美区或港区账号。
5. 认准 GitHub 官方发行版
绝不在第三方下载站下载带全家桶木马的客户端。
